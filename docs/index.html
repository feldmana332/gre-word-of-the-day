    Set up access token

    To enable the one-click Send now button, this device needs a small access token that lets it trigger the GitHub workflow.

    1. Open this pre-filled token form — scope and name are already set.
    2. Set Expiration to whatever you prefer (No expiration is fine).
    3. Scroll to the bottom and click the green Generate token button.
    4. Copy the token (starts with ghp_…) and paste it below.

    The token is stored only in this browser’s local storage. It can only trigger workflow runs in this repo (public_repo scope). You can remove it any time from the “This Device” section.
